Place your DWDM sales dataset here as sales_data.csv.

Required CSV columns:
Order_ID,Customer_ID,Order_Date,Sales

Order_Date should be parseable as a date (for example 2026-01-15).
Sales should contain numeric values.

The ZIP includes a small illustrative sample dataset. Replace it with your own
project dataset if its columns match, or update the analytics code to match your
dataset's actual column names.
